Project : Customer Churn Prediction for a Subscription-Based Business
Abstract
Subscription businesses need to identify customers who may discontinue their services. This project analyzes customer usage, billing and support information to discover churn-related patterns and develop a predictive solution. Semester III focuses on dataset sourcing, cleaning, merging, profiling and exploratory analysis. Later phases add statistical analysis, feature engineering, machine learning, visualization and Azure ML deployment with a Power BI retention dashboard.

Semester III Focus
Problem framing and stakeholder/decision identification

Dataset sourcing from public API/open-data source

Data loading, cleaning, merging and profiling

Exploratory data analysis and visual insights

Initial hypotheses/analytical questions

Git/GitHub project structure and four-semester roadmap

Expected Long-Term Outcome
A portfolio-ready project that starts with a clearly scoped Semester III plan and progressively incorporates the technical capabilities of Semesters IV–VI.
